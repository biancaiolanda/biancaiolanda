# Como instalar o perfil

Copie estes itens para a raiz do repositório `biancaiolanda/biancaiolanda`, mantendo exatamente as pastas:

```text
README.md
assets/
  bianca-pixel.gif
.github/
  workflows/
    snake.yml
```

Depois faça o commit na branch `main`.

A cobra será gerada pelo GitHub Actions. Abra a aba **Actions**, escolha **Generate contribution snake** e clique em **Run workflow**. Aguarde a execução terminar e atualize a página do seu perfil.

Se o GitHub bloquear a publicação, abra **Settings → Actions → General → Workflow permissions**, selecione **Read and write permissions** e salve. Depois execute o workflow novamente.
